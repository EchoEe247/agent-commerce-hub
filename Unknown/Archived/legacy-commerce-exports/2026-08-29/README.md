These files are preserved point-in-time outputs from the pre-Batch-7 Commerce Control exporter. They are historical evidence only and are not current-state authority.

Preserved by exact Git blob identity before retiring the active `*-latest.json` namespace:

- `services-latest.json` — `74eac508a8c54e1e0e50101b9d817051c3a12765`
- `work-latest.json` — `963facec4a4cf93fa8aa43c904190f07b00e1e24`
- `source-health-latest.json` — `f2969d7242a0ce9b5b03702f9ca1f6c44be403cc`

The Batch-7 exporter writes future non-authoritative snapshots under `analytics/commerce-control/legacy/` using `*-snapshot.json` names. It cannot regenerate these retired active-looking paths.
